# Coolicons in the Home/header prototype

The selected Coolicons assets were recovered from the existing PR16 proposal.
Their MIT notice is retained in LICENSE and embedded in the executable via app/src/main.rs.

Source package recorded by that proposal: @coolicons/svg 5.3.0, line/regular.
https://coolicons.cool/
https://coolicons.cool/license

The original 24x24 paths use white strokes for Slint colorize. The inherited stroke width is 1.8.
The Home/header prototype uses play, box, puzzle, settings, user and plus.
These intentional shapes differ from the provisional icons in the HTML proposal.

This file makes no Windows test claim for the current rework. See the review notes for tests actually performed.
